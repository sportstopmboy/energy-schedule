# Energy Price Prediction and Optimisation Model for Dynamic-Rate Energy Contracts in Belgium

An end-to-end quantitative machine learning and risk-managed execution framework designed to exploit wholesale electricity price volatility on the Belgian EPEX SPOT market. By modelling physical grid dynamics and weather conditions, this system optimises flexible energy consumption (e.g., EV charging, HVAC, industrial loads) under dynamic-rate contracts while hedging against asymmetric fat-tail price spikes.
